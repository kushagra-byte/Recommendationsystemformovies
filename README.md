# Recommendation system for movies

This project builds a Collaborative Filtering Recommendation System using TensorFlow and Keras to recommend movies to users.
It includes two main components:

Model Training: A neural network with user and movie embeddings that learns from rating data.
Recommendation Script / Streamlit App: Generates personalized movie recommendations for an anonymous user based on the trained model.

# Installation

Here are all the required installations:

    pip install tensorflow pandas numpy scikit-learn streamlit]

Optional (if you want graphs later):

   pip install matplotlib

Full recommended command:

    pip install tensorflow pandas numpy scikit-learn streamlit matplotlib

run file to train the model

# Usage

Run the command in command line :

    streamlit run app.py
